# Development toolchain, exact-pinned.
#
# Why pinned: CI previously ran `pipx install ruff`, which resolves to whatever the
# latest release happens to be. When ruff 0.16 widened its default rule set, CI started
# reporting 35 findings on code that had not changed, while a developer on an older ruff
# saw "All checks passed". A lint gate whose verdict depends on the day it runs cannot
# tell you whether your change is clean.
#
# Bump deliberately: change the version here, run `make lint`, fix what the new version
# finds, and commit both together.
#
# The validators in tools/ are stdlib-only by design and are not listed here.
ruff==0.16.7

# Validates the CloudFormation template under examples/. Pinned for the same reason as ruff:
# cfn-lint adds rules between minor versions, so an unpinned copy makes the verdict depend on
# the day it runs.
cfn-lint==1.57.0

# Runs PSScriptAnalyzer on the .ps1 files under examples/, which no gate looked at before this was
# added. It is a wrapper: it needs a PowerShell host on PATH, which GitHub-hosted runners already
# have and macOS does not. `make powershell` says how to install one and fails rather than skipping.
py-psscriptanalyzer==0.3.1

#   gitleaks            brew install gitleaks
#   shellcheck          brew install shellcheck
